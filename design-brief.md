# AM SRI Pet Shop - Modern Red & Black Home Page Design Brief

## OBJECTIVE
Create a production-ready, world-class modern home page for AM SRI Pet Shop & Aquarium with a bold red/black theme, cinematic animations, and premium UI that exceeds industry standards. The page must feature cutting-edge design trends but remain fully functional and accessible.

## TARGET AUDIENCE
- Pet owners in Virudhunagar, Tamil Nadu
- Aquarium enthusiasts and hobbyists
- Local customers seeking premium pet care products
- Modern shoppers who appreciate premium digital experiences

## AESTHETIC DIRECTION
**Ultra-modern cinematic cyberpunk luxury with pet-friendly warmth**
- Deep black pure (#000000) background with crimson red gradients (#dc2626 to #ef4444)
- Glassmorphism with backdrop blur (25px) and subtle red glow borders
- Floating animated orbs with neon red haze effects
- Particle field background with floating red embers
- Subtle scanline overlay for cinematic texture
- Animated gradient borders on all interactive cards
- Depth through layered z-index stacking
- Smooth micro-interactions on every hover state
- Cinematic scroll-triggered animations with stagger delays
- Morphing shapes that transform on scroll
- Audio-reactive subtle visual elements (optional)

## CONTENT STRUCTURE (Enhanced)
1. **HUD Navigation Bar** - Fixed top with glass effect, animated indicators, search modal
2. **Hero Section** - 3D floating hero image, animated particle field, morphing text, CTA with pulse effect
3. **Feature Marquee Strip** - Auto-scrolling marquee of trust badges with glow effects
4. **Categories Grid** - Interactive 3D cards that lift and rotate on hover, image parallax
5. **Stats Counter Section** - Animated number counters that increment on scroll, with wave effects
6. **About Section** - Split-screen with animated image reveal, timeline effects
7. **Services Showcase** - Expanding cards with inner carousel animations
8. **Featured Products Slider** - Infinite horizontal scroll with momentum physics
9. **Testimonials Carousel** - 3D rotating testimonials with depth effect
10. **Newsletter Section** - Glowing input field with submit animation that celebrates
11. **Interactive Map Footer** - Minimal map with animated location pin, social links with hover explosions

## TYPOGRAPHY DIRECTION
- Primary: Playfair Display (serif) for headings - cinematic, elegant, high contrast
- Secondary: Inter (sans-serif) for body - clean, modern, perfect readability
- Monospace: JetBrains Mono for UI elements, prices, and stats - technical precision
- Extreme scale hierarchy: 8rem hero headings → 0.75rem metadata
- Animated text characters with stagger reveal on scroll
- Text that creates a "wave" effect when scrolling into view

## ADVANCED ANIMATION REQUIREMENTS
1. **Page Load Sequence**: Staggered reveal of all page elements with subtle fade + slide
2. **Mouse Tracking**: Interactive background that follows cursor with subtle parallax
3. **Scroll-Synced Animations**: Elements that transform and morph based on scroll position
4. **Hover Micro-Interactions**: Every clickable element has 3+ state animations
5. **Loading Screen**: Animated pre-loader with pet-themed morphing logo
6. **Magnetic Buttons**: CTA buttons that attract cursor with smooth physics
7. **Smooth Scrolling**: Custom scroll physics with spring easing
8. **Text Morphing**: Hero text that transitions through different value propositions
9. **Floating Elements**: Decorative orbs that float with different bezier curves
10. **Glow Pulse**: Subtle border glow that breathes with CSS animations
