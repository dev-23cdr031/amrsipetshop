# Checkout and order operations brief

Objective: strengthen the existing AM SRI Petshop checkout, confirmation, and admin order-management experience without replacing its established Bootstrap/Inter dark commerce styling. The customer needs a dependable post-cart path; the admin needs immediate, understandable new-order and status feedback.

Audience: Indian pet-shop customers on mobile and store operators on desktop.

Aesthetic direction: retain the project’s dark, warm, polished commerce language. Prioritize clear price hierarchy, high-contrast validation/errors, calm progressive disclosure, and trustworthy payment/action states. Do not introduce a new visual system or external image URLs.

Required work: inspect and improve the current checkout flow, success/tracking screen, and admin live order interactions as necessary. Keep delivery permanently visible as a flat ₹100 fee. Make loading, empty, validation, submission, and real-time update states accessible and coherent. Reuse existing CSS/components where practical; application routes must remain the existing static pages.

Backend requirement context: checkout must be backed by server-authoritative pricing and stock validation; order creation persists an address object and uses PROCESSING/processing status. Real-time SSE exists and should remain dependable.
