# Guided cart checkout sheet

Objective: replace the existing abrupt slide-over success modal used from the home and products pages with a polished, step-by-step checkout that collects details before an order can be placed.

Audience: customers shopping AM SRI Petshop on mobile first, but also desktop.

Aesthetic direction: keep the site’s premium near-black visual language, with warm white typography and a restrained pet-shop green for success/primary actions. Make it feel like a compact, focused purchase journey: a clear numbered progress rail, generous card spacing, useful helper text, and a concise receipt-like review. Avoid generic forms and visual clutter.

Content structure:
1. Cart check and shipping details: required name, 10-digit phone, full street address, city, state, six-digit PIN. Inline validation and no order placement at this stage.
2. Review order: product thumbnails, title, quantity, unit/line prices; item subtotal, standard delivery ₹100, applicable tax, final payable amount; editable back action; selected Cash on Delivery messaging.
3. Processing state: disabled primary button/spinner while saving.
4. Confirmation: order ID/date, delivery address, purchased-items receipt, full cost breakdown, status tracker beginning at Processing, back-to-shop action. Never show success before the review confirmation has been deliberately submitted.

Technical requirements: use existing vanilla HTML/JS and the existing slide-over component rendered by public/script.js, shared by index.html and products.html. Preserve existing cart conventions but normalize the modal flow to `details`, `review`, `processing`, `success`. Submit to the current `/api/orders` contract using a structured address object; use server-returned totals/order ID when available and visibly report failures without clearing the cart. Delivery must always be ₹100. No remote images; reuse local product assets. Responsive and keyboard-friendly close/back controls.
